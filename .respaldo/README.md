# Yokohama versión integrada en EXCOBA

Copia de las fuentes del proyecto al 2026-10-22.

Origen: EXCOBA-PLATAFORMA-/yokohama.

Repositorio: https://github.com/mmoralescode/yokohama-desarrollo-respaldo

Rama de esta versión: version-integrada.

El manifiesto enumera los archivos incluidos y sus SHA256. Incluye los cambios locales disponibles en la fecha de copia. El historial Git anterior se identifica mediante su commit de origen; esta rama conserva una captura del contenido actual.

Se conservaron código, pruebas, documentación y recursos del proyecto. Se excluyeron configuraciones privadas, bases operativas, lotes de licencias, dependencias y archivos generados. Los archivos ignorados por el repositorio fuente tampoco se copiaron. Los datos sintéticos de demostración y materiales científicos disponibles se conservaron.

Las reglas de Git del respaldo amplían las exclusiones de credenciales y conservan los bytes de las fuentes; los archivos de configuración originales están archivados aquí cuando existían. Las otras variantes del proyecto están identificadas en las ramas del mismo repositorio. Las automatizaciones de GitHub Actions estarán desactivadas en estos repositorios de respaldo.
